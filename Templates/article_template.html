Fibonacci Memoization

The provided code gives the first 2000 fibonacci numbers using memoization. By storing previously calculated Fibonacci numbers in a dictionary, the program avoids redundant recursive calculations, significantly improving efficiency. Each Fibonacci number is computed only once, reducing the time complexity from exponential to linear, $O(n)$, at the cost of $O(n)$ additional memory.
